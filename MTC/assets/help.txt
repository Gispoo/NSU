Справка по оператору INPUT языка BASIC (упрощённый вариант)

Синтаксис оператора:

  INPUT ["подсказка"] (',' | ';') идентификаторы

Где:
  • "подсказка" — строковый литерал в двойных кавычках.
  • идентификатор — имя переменной:
        первая буква (A..Z, a..z),
        затем ноль или больше букв/цифр (A..Z, a..z, 0..9).
    Суффиксы $, %, & не используются.

Ключевые слова и идентификаторы РЕГИСТРОЗАВИСИМЫ:
  INPUT ≠ input, REM ≠ rem.

Комментарии:
  • REM ...  — комментарий до конца строки (только заглавными: REM).
  • ' ...    — комментарий до конца строки.

Примеры корректных строк:
  INPUT A
  INPUT A,B,C
  INPUT "Введите X:"; X
  INPUT "A,B:"; A,B
  INPUT "Имя и возраст", Name, Age
  INPUT   "Привет";   S
  INPUT X1, X2, X3
  INPUT "X,Y,Z", X, Y, Z
  INPUT Name
  INPUT "n:"; n

Некорректные примеры:
  INPT X         (опечатка ключевого слова)
  input A        (неверный регистр, ожидается INPUT)
  INPUT "X";     (нет списка переменных)
  INPUT ; X      (нет строки-подсказки перед ';')
  INPUT "X" X    (после строки нет ',' или ';')
  INPUT 1X       (имя не может начинаться с цифры)
  INPUT A,       (висячая запятая)
  INPUT "X"; , Y (лишняя запятая)
  REMX A         (REMX — уже не комментарий, а идентификатор + X)
